# الخصوصية في Vitra

- لا يحتاج الإصدار التجريبي إلى إنشاء حساب.
- لا يطلب الموقع أو جهات الاتصال أو الهاتف عند أول تشغيل.
- تُحفظ المفضلة وأنماط الألوان محليًا داخل التطبيق.
- بيانات البطارية والمساحة تُقرأ محليًا لعرض System Widget ولا تُرسل لأي جهة.
- التحليلات متوقفة افتراضيًا في هذا النموذج.
- يجب ألّا تُضاف خدمات إعلانية أو تحليلية مستقبلًا دون تحديث هذه الوثيقة وشاشة الخصوصية داخل التطبيق.
